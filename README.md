**Ghostty Code with a draggable widget overlay system, Obsidian integration, and plugin SDK.**

A fork of [blissito/ghosttycode](https://github.com/blissito/ghosttycode) that adds a widget engine — create floating, draggable panels inside the TUI that show live command output, markdown checklists, log tails, MCP server data, or static content.

---

## What's New

| Feature | Description |
|---------|-------------|
| **Widget SDK** | 500-line TOML-driven plugin system for draggable overlays |
| **5 widget types** | Script, FileWatch, LogTail, Static, McpView |
| **Drag & Drop** | Move panels with mouse — same pattern as sidebar resize |
| **Auto-discovery** | Drop a  in  |
| **Obsidian sync** | Point a FileWatch widget at your vault — live checkbox rendering |
| **Dashboard mode** | Alt-D for full-screen grid of all active widgets |
